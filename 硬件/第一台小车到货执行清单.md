# 第一台小车到货执行清单

设备：幻尔 TurboPi 旗舰版，树莓派 5 / 8G

目标：不要先研究全部官方功能，先验证宠物看护 MVP 所需的三个能力。

## 到货前可以做

### 1. 准备工作区

- 准备一张桌面或地面测试区域。
- 准备一个路由器或稳定 Wi-Fi。
- 准备电脑，用于 SSH/VNC/浏览器访问小车。
- 准备充电插座、螺丝刀、扎带、魔术贴。
- 准备测试目标：玩偶、纸箱、猫窝，真实宠物最后再测。

### 2. 先不要做的事

- 不要先装机械臂。
- 不要先改系统镜像。
- 不要先接毫米波。
- 不要先跑复杂大模型。
- 不要先研究全部 ROS/OpenClaw 教程。

第一天只验收底盘、摄像头和 Python 控制。

## 到货后第一天验收

### Step 1：开箱检查

确认包含：

- TurboPi 小车本体
- 树莓派 5 / 8G
- TF/SD 卡或系统镜像
- 摄像头
- 电池和充电器
- 手柄/接收器
- AI 语音交互盒
- 机械臂扩展包
- 螺丝配件
- 资料链接/源码链接

### Step 2：官方 Demo 跑通

只确认这些：

- 小车能开机。
- 手机 App 或 PC 端能连接。
- 摄像头画面能回传。
- 小车能前进、后退、左移、右移、原地旋转、停止。
- 低速运动可控。
- stop/急停有效。

### Step 3：找到源码目录

重点找这些文件或目录：

- 底盘运动控制：`chassis`、`car_control`、`motor`、`mecanum`、`controller`
- 摄像头读取：`camera`、`opencv`、`vision`
- 网页/图传：`web`、`flask`、`app`
- ROS 示例：`ros2`、`launch`、`cmd_vel`

### Step 4：最小 Python 控车

目标是写出或找到等价脚本：

```python
forward(speed=0.1)
sleep(1)
stop()
```

再确认：

```python
left()
right()
strafe_left()
strafe_right()
rotate_left()
rotate_right()
stop()
```

### Step 5：最小摄像头读取

目标是用 OpenCV 读到画面：

```python
import cv2

cap = cv2.VideoCapture(0)
ok, frame = cap.read()
print(ok, frame.shape if ok else None)
```

如果摄像头不是 `/dev/video0`，记录实际设备号。

## 第二天开始做 MVP

### MVP v0：手动复核版

流程：

```text
摄像头看到目标
→ 人手动控制小车靠近
→ 点击 stop
→ 截图/记录距离和宠物反应
```

先用玩偶测试，再用真实宠物测试。

### MVP v1：视觉静止检测

先不用毫米波：

```text
摄像头检测猫/狗
→ 每 5 秒记录位置框
→ 连续 1-3 分钟变化很小
→ 触发“久卧关注”
```

正式场景再把阈值改成 30-60 分钟。

### MVP v2：接毫米波

毫米波到货后：

```text
久卧关注
→ 小车靠近到 0.8-1.5m
→ 毫米波采样 60 秒
→ 记录 presence / motion / micro-motion / signal_quality
```

## 第一周成功标准

- Python 可以稳定控制小车。
- OpenCV 可以稳定读取摄像头。
- 小车能低速靠近并立即停止。
- 摄像头固定后画面不明显抖。
- 真实宠物没有明显被吓跑，或可通过低速/距离改善。

## 关键测试记录

每次测试记录：

- 日期时间
- 测试对象：玩偶/猫/狗
- 光线
- 地面材质
- 小车速度
- 靠近距离
- 是否成功停下
- 宠物是否逃开
- 摄像头画面是否稳定
- 备注

## 下一步采购

小车跑通后再买毫米波模块。优先选择：

- 支持 USB 或 UART。
- 有协议文档或 SDK。
- 能输出 presence / motion / micro-motion。
- 如果能输出 breathing trend 更好。
- 不依赖封闭手机 App。
